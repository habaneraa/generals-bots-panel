## 行为保持与有限改进

游戏与 agent 协议、动作提交语义、评分采样、SQLite 结构、录像格式和默认运行参数不变；前端现有展示不在本轮改动范围内。

可见变化仅有：自定义 `PORT` 自动用于开发代理；资源清理抛出非 Error 值时仍能保留原因，并增加资源上下文日志；失败收尾日志改为“已尝试关闭资源”。这些改进均未扩展产品能力或引入新配置项。

遗留事项为历史 hook 并发与 API client 的直接回归测试、WebSocket 传输层直接测试、锁文件镜像可移植性，以及缺失静态资源是否应返回 404 的边界确认。它们已记录为技术债，没有在不明确需求时擅自改变相关行为。

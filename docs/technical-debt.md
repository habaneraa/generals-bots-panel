## 已知边界，不自动扩展为需求

- 控制台是可执行本机命令的单用户本地工具，不适合通过代理暴露公网；本轮不设计用户系统、远程部署或权限框架。
- [进程清理](../apps/server/src/agent/process.ts)在 POSIX 使用进程组；Windows 基础 `child.kill` 不保证回收任意脚本后代，尚未做 Windows 实机验证。是否增加平台支持需另行确认。
- 日志与录像不自动清理；这属于现有保留策略，不据此擅自增加定时删除任务。使用者需关注磁盘和隐私。
- [旧 Python 目录](../browser_agent/README.md)为历史参考，不因本轮保留而恢复其维护或兼容承诺。
